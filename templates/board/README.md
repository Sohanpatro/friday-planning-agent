# Friday Board template (optional)

**The Board is optional.** Friday works without it, using the day template and defaults in `config/friday.config.md`. With a Board, Friday gets **more precise results**: it remembers your streaks and level, resolves clashes from options you've already decided on, follows your task rules, and learns from your log week to week.

## Set it up in 3 minutes
1. Create a Google Sheet named **Friday Board**.
2. For each CSV here, add a tab with the matching name (below), then use **File → Import → Upload → Replace current sheet**.
3. Put the sheet's ID in `config/friday.config.md`. Replace the sample rows with your own, or keep them as examples while you start.

| File | Tab name | What it holds |
|---|---|---|
| 01-canon.csv | Canon | State (level, streak, dates), setup, and stated personal facts |
| 02-day-template.csv | Day Template | Your Level 1 day, block by block |
| 03-ladder.csv | Ladder | Sessions per level and the unlock and drop rules |
| 04-day-shapes.csv | Day Shapes | Pre-decided options for each kind of clash |
| 05-task-rules.csv | Task Rules | Task priority and where each kind of task goes |
| 06-playbook.csv | Playbook | Close clock, short close, restart, amnesty |
| 07-wins-and-losses.csv | Wins & Losses | Nightly log, one row per day |
| 08-shortlist.csv | Shortlist | Tasks touched at the close |
| 09-week.csv | Week | Weekly scores |
| 10-open-questions.csv | Open Questions | Questions about your life, asked two at a time at most |
| 11-journal.csv | Journal | One system change at a time, with the evidence |
| 12-series.csv | Series | The standard calendar blocks Friday writes each week |

All sample data is made up.
