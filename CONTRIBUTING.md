# Contributing

Thanks for helping improve Friday.

- **Bugs / ideas:** open an issue with what you expected vs. what happened (redact personal calendar/task data).
- **Pull requests:** keep changes focused; if you change `SKILL.md`'s `description:`, re-run the prompts in `routing-eval.md` and record results.
- **New connectors:** add pull recipes to `references/connector-notes.md` with the date you verified them.
- **Never commit** personal data, tokens, or a filled-in `user-canon.md`.
